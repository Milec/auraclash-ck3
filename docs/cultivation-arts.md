# Transformations, Seals, Heavenly Gates and equipment: source fidelity

How each rule from the Aura Clash IF and the Core Rulebook is carried into CK3. **Same** means the rule is
kept as written (numbers checked against the source text). **Adapted** means a tabletop scene, day or
roll is scaled to CK3's months and years or mapped to a CK3 stat. **Simplified** lists what is left out.

## Transformation Techniques (IF `<<transform>>`, ch8–9)

| Source rule | In the mod | |
|---|---|---|
| One form per Style, Limitbreaker for Freestyle; Midorikatai picks Titan or Asura | Same seven forms; Titan and Asura exclude each other | Same |
| Bonuses (`[+2 Power, +1 Agility, +1 Health]` and so on) | Core points (+2 to that Core's Clash roll each), Health as Vitality, Chi refunded | Same |
| `tfboost`: +500 AP, or 250 + AP/8 from 2,000 AP | Added to Aura Pressure for suppression in the Clash | Same |
| Limitbreaker: all Core Surges +1, +10 AP from battle victories | Surges +1 in the Clash; +10 battle AP | Same |
| Reaper doubles a bladed mainhand's bonuses | Equipment Core bonuses doubled with a bladed weapon | Same |
| Godhand heals to full upon transforming | Vitality to full | Same |
| Soul Domain: all attacks Focused | +1 to every roll | Adapted |
| Malocchio: Technique Copy | A victory teaches one of the foe's attack Techniques | Same |
| Titan: always trigger bonus damage | +1 damage on every hit | Same |
| Asura: melee always Focused, dual wielding | +1 to the three melee moves | Simplified: no second weapon slot |
| The MC awakens a form by drawing a whole Heavenly Gate (`powerofgate`) | Gate option: chance from level and Martial; failure wounds | Same |
| The author: anyone can train for one | A personal scheme, alone or under a master | Adapted |

|---|---|---|

| Handseals roll: d6 pool, success on 5–6, exploding sixes | 2 + rank dice, the same rule | Same |
| Cast Time | Instant (interactions resolve at once) | Simplified |
| Durations per success (days, scenes) | Months per success; Spiritbinding's ladder kept (3, 6, 12 months, permanent at 5) | Adapted |
| Craft Shard: 1 Shard per success, once a day | 10 gold per success, every 3 months | Adapted |
| Reinforcement: harder by 100 AP per 2 successes | +2 prowess, knight effectiveness; equipment regains durability | Adapted |
| Four Winds: +1d10 to a skill for caster and allies, one skill until rested | +3 skill (+5 prowess) for caster, target and a courtier per extra success; yearly cooldown | Adapted |
| Keystone: permanent lock | Permanent modifier until Counterseal | Same |
| Counterseal: contested; fail locks you out | Succeeds if successes ≥ the caster's; one try per target a year | Same |
| Reinforcement (Improved): permanent on the weapon; Crowd +1 Power | Weapon modifier; +10% pikemen and heavy infantry damage | Same |
| Soulsoak: X00 AP into a blade; end for +1 success, untap AP or heal | 2 or 4 charges; release in a Clash for +3, or outside combat to heal a wound; each release restores 1 spent Chi | Same |
| Celestial Forge: exchange your Foundation | Choose any other Foundation, keeping its tempering | Same |
| Exorcism: dead laid to rest; skill boon [Core+3] | County modifier; +3 to a chosen skill | Adapted |
| Prayer Engine: hear prayers within 100 miles per success | Piety and same-faith opinion; enables Divine Intervention | Adapted |

| Scry: view a place | Reveals the target's secrets; Ward and Mask block | Adapted |

| Charm: contested by Survival or Persuasion; failure turns hostile | Contested by Diplomacy or prowess; +40 or −20 opinion | Same |
| Spiritbinding: a spirit of your choice; cost by the spirit's AP | Earth, Water, Wisp or Kami tasks; flat 300 AP | Simplified: spirits are not characters |
| Hex: Power Clash; Disadvantage on the next skill roll | Aura Pressure contest; a skill penalty for a year | Adapted |
| Thousand-Face Mask: new appearance and masked aura | Scheme success and secrecy; blocks Scry | Adapted |
| Puppetmaster: target ≤10% of your AP (50% helpless); 3 successes; duration ladder | Same limits; a strong "Puppet" hook from a month to permanent | Same |
| Subjugation Domain: one domain, Advantage on Perception and Survival | Modifiers on the county you stand in; one at a time | Same |
| Alpha Seal: a Beast brought to 0 AP; one at a time | A Beast slain within the year; one Alpha modifier | Same |
| Unlock Potential: 100 + 100 per 1,000 AP to someone under half yours | Same amounts, paid as cost | Same |

## Heavenly Gates and spirit fruit

| Source rule | In the mod | |
|---|---|---|
| An area's aura surges for a while; "a trickle every season" in the Outer lands | Six Gates a year, each lasting a season, levels by region | Same |
| Rulebook: level 5–15; successes added to the level, up to triple | Same formula, rolled from Athletics or Insight (prowess or learning) | Same |
| Finite chi: every extra cultivator takes less | Shared out beyond three cultivators | Same |
| Sects claim Gates; rivals ambush there | Contest the local sect's disciples in a Clash; AI sects claim unclaimed Gates | Same |
| The first cultivation drains the Gate | Drained when the activity ends | Same |
| Spirit fruit: +8 or +10 AP, less each time | +10, divided by fruit eaten that year | Same |
| Sects hide Soulfruit Groves; a skill check learns where one is | Groves start hidden; rumours (and a Heavenly Message) name the duchy; the Seek the Rumoured Grove activity searches with Perception or Insight dice; found groves become special buildings | Same |
